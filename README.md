# Triton2Go GPT

Triton2Go GPT is a food recommendation website for UC San Diego students. Users can type what they're looking for into a chatbot and get food suggestions based on information collected from Triton2Go.

We built this project during UCSD's Summer Program for Incoming Students (SPIS). We wanted to help students decide what to eat on campus without having to look through every menu themselves.

## What It Does

- Recommends food based on preferences like vegan or vegetarian options.
- Helps users find food based on calories and protein.
- Lets users ask for food from a specific campus dining location.
- Includes nutrition information and the dining location with food suggestions.

For example, someone could ask, "What vegan food can I get under 500 calories?"

## Built With

- HTML, CSS, and JavaScript for the website
- Python and Flask to connect the website to the recommendation code
- pandas to work with the food data
- Used gpt-oss-120b through Hugging Face for the chatbot
